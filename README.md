# Divisibility Using Modular Arithmetic

## 📖 Description

This project demonstrates an efficient mathematical approach to solving divisibility problems using modular arithmetic. Instead of repeatedly incrementing a number until it becomes divisible, the algorithm calculates the minimum required increment directly from the remainder. The solution is optimized for handling multiple test cases efficiently and is commonly used in competitive programming due to its simplicity, speed, and constant extra space usage.

## 🚀 Features

- Efficient remainder-based calculation
- Handles multiple test cases
- Linear time complexity
- Constant extra space
- Beginner-friendly implementation

## 💻 Language

- JavaScript (Node.js)

## ⏱ Complexity

- **Time:** O(t)
- **Space:** O(1)
